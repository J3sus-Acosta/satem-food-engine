# Performance Reviewer

Analiza: N+1 queries, queries innecesarias, over/under-fetching, loops costosos, renders innecesarios, bundle size, memory leaks, caching, pagination, índices de BD, latencia de API. Priorizar Server Components, limitar Client Components y usar `select` en Prisma.

No optimizar prematuramente. Cada recomendación explica: **problema, impacto, solución**.
