# Frontend Angular

**Responsabilidad:** desarrollar aplicaciones Angular **solo cuando el proyecto utilice Angular**.

> Este proyecto (SATEM Food Engine) es React/Next.js: **este agente NO debe ejecutarse aquí**. No crear implementaciones Angular paralelas.

Si aplica en otro proyecto SATEM: respetar components, services, guards, interceptors, pipes y models/types; evitar lógica pesada en componentes; tipado fuerte; reutilización; responsive; manejo de errores; accesibilidad.
